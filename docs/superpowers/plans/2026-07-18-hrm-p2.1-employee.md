# HRM Phase 2.1 — Hồ sơ nhân viên + Onboarding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) tracking.

**Goal:** Chức năng "Hồ sơ nhân viên" đầu tiên của HRM: quản lý hồ sơ điện tử nhân viên (CRUD + list/filter) và Onboarding (sinh Employee ID, chống trùng CCCD/MST), chạy trên app `nhan-su` đã deploy.

**Architecture:** BE thêm module `nhan-vien` trong `config-service` (mirror module `vai-tro`), entity `Employee` trong DB `nhan_su`, expose qua gateway sẵn có `/api/config/nhan-vien`. FE thêm feature `ho-so-nhan-vien` theo CHanlder pattern (mirror `vai-tro`), thêm mục sidebar "Nhân sự". Không đụng identity/master-seo/task-management.

**Tech Stack:** NestJS 11 + TypeORM (MongoDB), Jest; React 18 + Vite + antd 6 + CHanlder/RxJS; Node 22 builds.

## Global Constraints
- Chỉ sửa trong `hrm/`. Không đụng 3 project cũ.
- BE route sẵn: gateway proxy `/config` → config-service; endpoint mới nằm dưới `/api/config/nhan-vien`.
- Entity mới tenant-aware (kế thừa `BaseEntity`, DB proxy tự lọc `tenantId`).
- Node 22 cho mọi build/test: `nvm use v22.0.0`.
- Mỗi task: test/verify xanh + 1 commit.
- Employee ID format: `NV` + 4 chữ số, unique trong tenant (vd `NV0001`).
- Deploy cuối: rebuild container `nhan-su-be` + `nhan-su-fe` trên server kt (`/root/chimseo/nhan-su`, `docker compose -f docker-compose.production.yml up -d --build`).

- Modify: `be/libs/entities/src/index.ts`

**Interfaces:**
- Produces: `Employee` (collection `employees`) + `EmployeeCounter` (collection `employee_counters`), exported from `@app/entities`.

- [ ] **Step 1:** Create `employee.entity.ts`:
```ts
import { Entity, Column } from 'typeorm';
import { BaseEntity } from '../base.entity';

export interface BangCap { ten: string; noiCap?: string; nam?: string; }
export interface NguoiPhuThuoc { hoTen: string; quanHe?: string; ngaySinh?: string; giayTo?: string; }
export interface LienHeKhanCap { hoTen?: string; quanHe?: string; soDienThoai?: string; }

@Entity('employees')
export class Employee extends BaseEntity {
  @Column() employeeId: string;                 // NV0001 (unique per tenant, enforced in service)
  @Column() hoTen: string;
  @Column({ nullable: true }) ngaySinh?: string;
  @Column({ nullable: true }) gioiTinh?: string;       // nam|nu|khac
  @Column() cccd: string;
  @Column({ nullable: true }) mst?: string;
  @Column({ nullable: true }) soDienThoai?: string;
  @Column({ nullable: true }) email?: string;
  @Column({ nullable: true }) diaChi?: string;
  @Column({ nullable: true }) phongBan?: string;
  @Column({ nullable: true }) chucDanh?: string;
  @Column({ nullable: true }) ngayVaoLam?: string;
  @Column({ default: 'thu_viec' }) loaiHopDong: string;   // thu_viec|chinh_thuc|dich_vu
  @Column({ default: 'dang_lam_viec' }) trangThai: string; // dang_lam_viec|da_nghi|tam_nghi
  @Column('json', { nullable: true }) bangCap?: BangCap[];
  @Column('json', { nullable: true }) nguoiPhuThuoc?: NguoiPhuThuoc[];
  @Column('json', { nullable: true }) lienHeKhanCap?: LienHeKhanCap;
  @Column({ default: true }) isActive: boolean;
}

@Entity('employee_counters')
export class EmployeeCounter extends BaseEntity {
  @Column() seq: number;   // last used sequence for this tenant
}

export interface NhanSuEntities { Employee: typeof Employee; EmployeeCounter: typeof EmployeeCounter; }
declare module '../entities' { interface Entities extends NhanSuEntities {} }
```
- [ ] **Step 2:** `nhan-su/index.ts`: `export * from './employee.entity';`
- [ ] **Step 3:** Add to `be/libs/entities/src/index.ts`: `export * from './nhan-su';`
- [ ] **Step 4:** Verify build: `nvm use v22.0.0 && cd be && yarn build:config` PASS.
- [ ] **Step 5:** Commit: `feat(be): Employee + EmployeeCounter entities`.

### Task 2: nhan-vien module — service (onboarding logic, TDD) + controller

**Files:**
- Create: `be/apps/config-service/src/nhan-vien/nhan-vien.service.ts` (+ `.spec.ts`), `nhan-vien.controller.ts`, `nhan-vien.module.ts`, `dto/create-employee.dto.ts`, `dto/update-employee.dto.ts`
- Modify: `be/apps/config-service/src/config-service.module.ts`

**Interfaces:**
- Consumes: `Employee`, `EmployeeCounter` from `@app/entities`.
- Produces: `NhanVien_Service` with `create(dto)` (dedup CCCD/MST + gen employeeId), `findAll(filter)`, `findOne(id)`, `update(id,dto)`, `remove(id)` (soft), `updateStatus(id, trangThai)`. Controller `@Controller('nhan-vien')` guarded `JwtGuard`.

- [ ] **Step 1 (RED):** Write `nhan-vien.service.spec.ts` covering: (a) `create` sinh employeeId `NV0001` rồi `NV0002`; (b) `create` với CCCD trùng → throw ConflictException; (c) `create` với MST trùng (khi MST có giá trị) → ConflictException; (d) `findAll` trả list; (e) `remove` set isActive=false. Mock repositories (Employee repo + EmployeeCounter repo). Run: `yarn test nhan-vien.service` → FAIL.
- [ ] **Step 2 (GREEN):** Implement `nhan-vien.service.ts`:
  - `generateEmployeeId(tenantId)`: đọc/khởi tạo `EmployeeCounter` (1 doc/tenant), `seq+1`, lưu, trả `'NV' + String(seq).padStart(4,'0')`.
  - `create(dto)`: check trùng `cccd` (và `mst` nếu có) qua repo.findOne → nếu có throw `ConflictException('CCCD/MST đã tồn tại')`; gen employeeId; save.
  - `findAll(filter?)`: repo.find (hỗ trợ filter `hoTen`/`phongBan`/`trangThai` optional, mặc định isActive=true).
  - `findOne`, `update`, `remove` (soft: isActive=false), `updateStatus`.
  Run `yarn test nhan-vien.service` → PASS.
- [ ] **Step 3:** DTOs với class-validator: `CreateEmployeeDto` (hoTen, cccd bắt buộc; còn lại optional; bangCap/nguoiPhuThuoc là array optional). `UpdateEmployeeDto` (partial).
- [ ] **Step 4:** Controller mirror `vai-tro.controller.ts`: `@Controller('nhan-vien') @UseGuards(JwtGuard)` — `GET /` (findAll, đọc query filter), `GET /:id`, `POST /` (create), `PUT /:id`, `DELETE /:id`, `PATCH /:id/trang-thai`.
- [ ] **Step 5:** `nhan-vien.module.ts` mirror vai-tro: `DatabaseModule.forFeature([Employee, EmployeeCounter])`. Register `NhanVien_Module` trong `config-service.module.ts` imports.
- [ ] **Step 6:** Verify: `nvm use v22.0.0 && cd be && yarn build:config && yarn test nhan-vien` PASS.

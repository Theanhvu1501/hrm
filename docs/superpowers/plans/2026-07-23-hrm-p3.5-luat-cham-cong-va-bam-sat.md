## Task 3: Không quay lại chấm vào; cho phép chấm ra lặp lại

**Files:**
- Modify: `be/apps/config-service/src/ban-ghi-cham-cong/ban-ghi-cham-cong.service.ts`
- Test: `be/apps/config-service/src/ban-ghi-cham-cong/ban-ghi-cham-cong.service.spec.ts`

**Interfaces:**
- Produces: `homNay().hanhDongKeTiep` đổi cách tính; `checkOut` nhận lượt ra thứ hai trong cùng ngày công.

**Hai thay đổi, phải làm cùng nhau.** Làm một cái thôi thì màn hình bảo "bấm để chấm ra" rồi backend trả 409 — tệ hơn hiện trạng.

**(a) `hanhDongKeTiep` tính từ bản ghi của ngày công, không từ "lượt vào còn hiệu lực".**

Hôm nay: `hanhDongKeTiep: dangMoLuotVao ? 'ra' : 'vao'`, mà `dangMoLuotVao = luotVaoConHieuLuc(cuoi, bayGio)` chỉ đúng khi lượt vào thuộc hôm nay/hôm qua — nên lượt vào treo 3 ngày làm nút **quay về "vào"**.

Mới: ngày công đang xét đã có ít nhất một lượt `vao` → luôn `'ra'`.

`ngayCong` **giữ nguyên** cách suy hiện tại (nó xử lý ca qua đêm đúng); chỉ đổi cách tính `hanhDongKeTiep` từ mảng `banGhi` đã lấy về.

**(b) `checkOut` cho phép lượt ra thứ hai trong cùng ngày công.**

Guard hiện tại (`ban-ghi-cham-cong.service.ts:148-152`) ném 409 khi bản ghi cuối là `ra`:

```ts
if (!cuoi || cuoi.loai === 'ra') {
  throw new ConflictException('Chưa có lượt check-in nào đang mở để check-out.');
}
```

Phải nới: chỉ ném khi ngày công **chưa có lượt vào nào**. Nếu đã có `vao` và bản ghi cuối là `ra` thì cho ghi thêm một `ra` mang **cùng `ngay`** với lượt `vao` đó — đó chính là "lượt cuối thắng".

Ngưỡng chống trùng 60 giây (`vuaMoiBam`) vẫn đứng trước, nên hai cú chạm liền nhau không đẻ rác.

- [ ] **Step 1: Viết test thất bại**

     * Nhánh mà hôm nay trả về 'vao': lượt vào treo quá hạn. Sau P3.5 nút KHÔNG

- [ ] **Step 3: Viết `ngayDangXem.ts`**

```ts
import {
  AttendanceRecord,
  TrangThaiHomNay,
} from '@/services/attendanceRecordService';

/**
 * Ngày được chọn sẵn khi mở một tuần.
 *
 * Tuần chứa hôm nay thì chọn hôm nay — đó là thứ người ta mở app để xem.
 * Tuần khác thì chọn ngày đầu tuần, để không trỏ vào một ngày của tuần cũ.
 */
export function ngayMacDinhCuaTuan(dauTuan: string, homNay: string): string {
  const bayNgay = Array.from({ length: 7 }, (_, i) => {
    const d = new Date(`${dauTuan}T00:00:00Z`);
    d.setUTCDate(d.getUTCDate() + i);
    return d.toISOString().slice(0, 10);
  });
  return bayNgay.includes(homNay) ? homNay : dauTuan;
}

function suySoCong(banGhi: AttendanceRecord[]): number | null {
  const coVao = banGhi.some((b) => b.loai === 'vao');
  const coRa = banGhi.some((b) => b.loai === 'ra');
  if (coVao && coRa) return 1;
  if (coVao) return null;
  return 0;
}

/**
 * Dữ liệu để vẽ 3 ô và khối chi tiết cho MỘT ngày.
 *
 * Hôm nay CỐ Ý lấy từ `homNay` chứ không từ `banGhiTuan`: dải tuần chỉ nạp
 * lại khi đổi tuần, nên ngay sau cú chấm công nó đã cũ — người vừa bấm sẽ
 * không thấy lượt của chính mình.
 *
 * `soCong` của hôm nay dùng số backend tính; ngày khác suy tại chỗ theo cùng
 * luật, vì backend chỉ tính cho ngày công đang mở.
 */
export function duLieuNgay(
  ngay: string,
  homNay: string,
  homNayData: TrangThaiHomNay | null,
  banGhiTuan: AttendanceRecord[]
): { banGhi: AttendanceRecord[]; soCong: number | null; laHomNay: boolean } {
  if (ngay === homNay) {
    return {
      banGhi: homNayData?.banGhi ?? [],
      soCong: homNayData?.soCong ?? 0,
      laHomNay: true,
    };
  }
  const banGhi = banGhiTuan.filter((b) => b.ngay === ngay);
  return { banGhi, soCong: suySoCong(banGhi), laHomNay: false };
}
```

# P3.10 — Phép năm tích theo công thực tế — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ngày phép năm chỉ được tích khi nhân viên thực sự làm ≥50% số ngày làm việc của tháng — đọc từ bảng công đã chốt, không đoán theo lịch.

**Architecture:** Ba hàm thuần mới trong `luat-phep.ts` (ngưỡng, phép một tháng, danh sách tháng theo luật cũ để backfill); một method `tichPhepTheoThang()` trên `QuyPhep_Service` được `BangCong_Service.chotKy()` gọi sau khi khoá số; `LeaveBalance.thangDaTich` chống cấp trùng và cũng là thứ giữ cho quỹ đã cấp không bị hạ.

**Tech Stack:** NestJS 10 + TypeORM (MongoDB), Jest; React 18 + Vite + antd + Vitest; yarn (be), npm (fe); Node 22.

**Spec:** `docs/superpowers/specs/2026-08-04-hrm-p3.10-phep-theo-cong-thuc-te-design.md`

## Global Constraints

- **Node 22.** `cd be && nvm use v22.0.0`; `cd fe && nvm use`.
- **Baseline:** backend `yarn test` xanh (một test `AuthServiceService › Property 8: Password Hashing` nằm sát mốc timeout 5s của Jest, đỏ ngẫu nhiên và đỏ cả trên `main` — không phải hồi quy). `tsc --noEmit -p tsconfig.json` ra đúng **70** dòng. FE `npm run test` xanh, `tsc --noEmit` sạch.
- **TUYỆT ĐỐI không hạ `soNgayDuocCap` của quỹ đang có.** Production đang có 4 quỹ, một quỹ **đã dùng 2 ngày**, và **11 bảng công đều còn `nhap`**. Hạ số là đẩy quỹ xuống âm cho người đã nghỉ.
- **Công hợp lệ = `soNgayCong + soNgayOm`.** `Timesheet.soNgayCong` KHÔNG gồm nghỉ ốm — bảng ký hiệu (`bang-cong/cham-cong-ky-hieu.ts`) quy `O` = 0 công, còn `P`/`L`/`NB`/`CT` = 1 công. Lấy thẳng `soNgayCong` là bỏ mất ngày ốm.
- **Mẫu số vẫn theo LỊCH** — "50% số ngày làm việc *bình thường* của tháng" là con số của lịch, không của người. Chỉ tử số đổi sang thực tế.
- **Chỉ đọc bảng công `chot`.** Bảng công `nhap` sửa được; tích theo nó thì số dư phép tụt sau khi nhân viên đã nhìn thấy.
- **Mở lại bảng công KHÔNG thu hồi ngày đã tích** — nhân viên có thể đã nghỉ bằng số đó; thu hồi là đẩy quỹ xuống âm.

```ts
/** Số ngày làm việc theo LỊCH của một tháng. Đây là MẪU SỐ của ngưỡng 50%. */
export function soNgayLamViecCuaThang(input: {
  nam: number;
  thang: number;
  ngayLamViecTrongTuan?: number[];
}): number {
  const dauThang = Date.UTC(input.nam, input.thang - 1, 1);
  const cuoiThang = Date.UTC(input.nam, input.thang, 0);
  let so = 0;
  for (let t = dauThang; t <= cuoiThang; t += MOT_NGAY) {
    if (laNgayLamViec(t, input.ngayLamViecTrongTuan)) so += 1;
  }
  return so;
}

/**
 * Tháng có được tính là một tháng làm việc không.
 *
 * `>=` chứ không `>`: NĐ 145/2020 Đ66.2 nói "ít nhất 50%". Mẫu số 0 trả `false`
 * chứ không chia cho 0.
 */
export function datNguongThangLe(input: {
  congHopLe: number;
  soNgayLamViecChuan: number;
}): boolean {
  if (input.soNgayLamViecChuan <= 0) return false;
  return input.congHopLe >= NGUONG_THANG_LE * input.soNgayLamViecChuan;
}

/**
 * Phép của MỘT tháng. KHÔNG làm tròn ở đây: `lamTronLen05()` áp cho từng tháng
 * biến 13/12 = 1,083 thành 1,5 ⇒ 18 ngày/năm thay vì 13. Cộng số thô vào quỹ,
 * làm tròn ở tầng hiển thị và khi trừ phép.
 */
export function phepMotThang(mucCaNam: number): number {
  return mucCaNam / 12;
}

/**
 * Các tháng mà LUẬT CŨ (đếm theo lịch, không đọc bảng công) đã tính cho `nam`.
 *
 * Chỉ dùng cho script backfill `thangDaTich`: nó phải trả về ĐÚNG tập tháng mà
 * lần cấp cũ đã tính, nếu không tháng lệch sẽ được cấp lần thứ hai khi bảng
 * công tháng đó được chốt.
 */
export function thangTheoLich(input: {
  ngayVaoLam: string;
  nam: number;
  ngayLamViecTrongTuan?: number[];
}): string[] {
  const mocVao = moc(input.ngayVaoLam);
  const ds: string[] = [];

  for (let thang = 1; thang <= 12; thang += 1) {
    const dauThang = Date.UTC(input.nam, thang - 1, 1);
    const cuoiThang = Date.UTC(input.nam, thang, 0);
    if (mocVao > cuoiThang) continue;

    const tongNgayLamViec = soNgayLamViecCuaThang({
      nam: input.nam,
      thang,
      ngayLamViecTrongTuan: input.ngayLamViecTrongTuan,
    });
    let ngayLamViecConLai = 0;
    for (let t = dauThang; t <= cuoiThang; t += MOT_NGAY) {
      if (!laNgayLamViec(t, input.ngayLamViecTrongTuan)) continue;
      if (t >= mocVao) ngayLamViecConLai += 1;
    }

    if (
      datNguongThangLe({
        congHopLe: ngayLamViecConLai,
        soNgayLamViecChuan: tongNgayLamViec,
      })
    ) {
      ds.push(`${input.nam}-${String(thang).padStart(2, '0')}`);
    }
  }

  return ds;
}
```

```ts
  /**
   * Tích phép của MỘT tháng vào quỹ, dựa trên bảng công ĐÃ CHỐT.
   *
   * Gọi từ `BangCong_Service.chotKy()`. Idempotent qua `thangDaTich` — chốt
   * lại một tháng đã tích không cộng thêm ngày nào.
   *
   * KHÔNG bao giờ hạ `soNgayDuocCap`: nhân viên có thể đã nghỉ bằng số phép
   * đó rồi, hạ xuống là đẩy quỹ về âm. Tháng không đạt ngưỡng chỉ đơn giản là
   * không cộng gì.
   *
   * `dsBangCong` truyền vào chỉ dùng cho test; đường production để trống và
   * hàm tự đọc từ repo.
   */
  async tichPhepTheoThang(
    thang: string,
    nguoiThucHien: string,
    dsBangCong?: Timesheet[],
  ): Promise<{
    soNguoiDuocTich: number;
    soNguoiKhongDat: number;
    soNguoiDaTich: number;
  }> {
    const rows =
      dsBangCong ??
      (await this.timesheetRepo.find({ where: { thang, isActive: true } as any }));
    const nam = Number(thang.split('-')[0]);
    const thangSo = Number(thang.split('-')[1]);

    let soNguoiDuocTich = 0;
    let soNguoiKhongDat = 0;
    let soNguoiDaTich = 0;

    for (const bc of rows) {
      // Bảng công nháp còn sửa được — tích theo nó thì số dư phép tụt sau khi
      // nhân viên đã nhìn thấy.
      if (bc.trangThai !== 'chot') continue;

      const employeeId = String(bc.employeeId);
      const quy = await this.timQuy(employeeId, nam);
      if (!quy) continue; // chưa có quỹ năm đó — chưa lên chính thức

      const daTich = quy.thangDaTich ?? [];
      if (daTich.includes(thang)) {
        soNguoiDaTich += 1;
        continue;
      }

      const nv = await this.nvRepo.findOne({
        where: { _id: new (await import('mongodb')).ObjectId(employeeId) as any },
      });

      // `soNgayCong` KHÔNG gồm ngày ốm (bảng ký hiệu quy `O` = 0 công), mà NĐ
      // 145 Đ65 tính nghỉ ốm hưởng BHXH là thời gian làm việc.
      const congHopLe = (bc.soNgayCong ?? 0) + (bc.soNgayOm ?? 0);
      const soNgayLamViecChuan = soNgayLamViecCuaThang({
        nam,
        thang: thangSo,
        ngayLamViecTrongTuan: nv?.ngayLamViecTrongTuan,
      });

      if (!datNguongThangLe({ congHopLe, soNgayLamViecChuan })) {
        soNguoiKhongDat += 1;
        continue;
      }

      const themNgay = phepMotThang(quy.canCuCap?.mucCaNam ?? PHEP_CO_BAN);
      quy.soNgayDuocCap += themNgay;
      quy.thangDaTich = [...daTich, thang];

      await this.ghi(quy, {
        soNgay: themNgay,
        lyDo: 'tich_theo_thang',
        nguoiThucHien,
        ghiChu: `Tháng ${thang}: ${congHopLe}/${soNgayLamViecChuan} công`,
      });
      soNguoiDuocTich += 1;
    }

    return { soNguoiDuocTich, soNguoiKhongDat, soNguoiDaTich };
  }
```

`PHEP_CO_BAN` từ `./luat-phep`.

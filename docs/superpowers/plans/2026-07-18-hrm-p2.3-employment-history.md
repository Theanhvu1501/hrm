# HRM Phase 2.3 — Quá trình công tác (versioning) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Checkbox tracking.

**Goal:** Ghi nhận lịch sử biến động của nhân viên (điều chuyển phòng ban/chức danh, đổi trạng thái, tăng lương theo quyết định) với ngày hiệu lực + versioning: mỗi thay đổi lưu giá trị cũ→mới và cập nhật hồ sơ nhân viên sang giá trị mới.

**Architecture:** BE module `qua-trinh-cong-tac` trong `config-service` (mirror `hop-dong`/`nhan-vien`), entity `EmploymentHistory` trong DB `nhan_su`, expose `/api/config/qua-trinh-cong-tac`. Điểm khác: `create()` đọc `Employee` để snapshot giá trị hiện tại làm "cũ" và **ghi đè** các trường tương ứng trên `Employee`. FE feature `qua-trinh-cong-tac` (CHanlder), sidebar "Nhân sự → Quá trình công tác". Không đụng 3 project cũ.

**Tech Stack:** NestJS 11 + TypeORM Mongo, Jest; React 18 + Vite + antd 6 + CHanlder; Node 22.

## Global Constraints
- Chỉ sửa trong `hrm/`. Không đụng identity/master-seo/task-management. Node 22 builds.
- Entity tenant-aware. **Truy vấn Mongo: dùng `find({where})`/`findOne({where})`, KHÔNG dùng `repo.count({where})`** (MongoRepository bỏ qua `where` → bug âm thầm; xem hop-dong đã sửa).
- **DEPLOY: rsync PHẢI có `--exclude=env`** (env server là nguồn chân lý). Sau đó `docker compose -f docker-compose.production.yml up -d --build`.
- Mỗi task: verify xanh + 1 commit. Verify thật trên server sau deploy (không chỉ unit test — bài học P2.2).

### Task 1: EmploymentHistory entity (BE)
**Files:** Create `be/libs/entities/src/nhan-su/employment-history.entity.ts`; Modify `nhan-su/index.ts`.
**Interfaces:** Produces `EmploymentHistory` (collection `employment_histories`) exported from `@app/entities`.

- [ ] **Step 1:** Create entity (mirror `labor-contract.entity.ts` style + `declare module` augmentation):
```ts
import { Entity, Column } from 'typeorm';
import { BaseEntity } from '../base.entity';

@Entity('employment_histories')
export class EmploymentHistory extends BaseEntity {
  @Column() employeeId: string;
  @Column({ nullable: true }) employeeName?: string;   // denormalized
  @Column({ nullable: true }) employeeCode?: string;   // denormalized NV####
  @Column() loaiThayDoi: string;   // dieu_chuyen|tang_luong|bo_nhiem|doi_trang_thai|danh_gia
  @Column() ngayHieuLuc: string;
  @Column({ nullable: true }) phongBanCu?: string;
  @Column({ nullable: true }) phongBanMoi?: string;
  @Column({ nullable: true }) chucDanhCu?: string;
  @Column({ nullable: true }) chucDanhMoi?: string;
  @Column({ nullable: true }) trangThaiCu?: string;    // dang_lam_viec|tam_nghi|da_nghi
  @Column({ nullable: true }) trangThaiMoi?: string;
  @Column({ nullable: true }) mucLuongCu?: number;     // thông tin quyết định
  @Column({ nullable: true }) mucLuongMoi?: number;
  @Column({ nullable: true }) soQuyetDinh?: string;
  @Column({ nullable: true }) lyDo?: string;
  @Column({ nullable: true }) ghiChu?: string;
  @Column({ default: true }) isActive: boolean;
}

export interface QuaTrinhEntities { EmploymentHistory: typeof EmploymentHistory; }
declare module '../entities' { interface Entities extends QuaTrinhEntities {} }
```
- [ ] **Step 2:** `nhan-su/index.ts`: thêm `export * from './employment-history.entity';`
- [ ] **Step 3:** Verify `nvm use v22.0.0 && cd be && yarn build:config` PASS. Commit: `feat(be): EmploymentHistory entity`.

### Task 2: qua-trinh-cong-tac module — service (snapshot + apply, TDD) + controller
**Files:** Create `be/apps/config-service/src/qua-trinh-cong-tac/{service(+spec),controller,module,dto/{create,update}-*.dto.ts,dto/index.ts}`; Modify `config-service.module.ts`.
**Interfaces:** `QuaTrinhCongTac_Service`: `create(dto)` (snapshot Employee hiện tại → lưu history cũ/mới → cập nhật Employee), `findAll(filter?)` (filter employeeId/loaiThayDoi), `findOne(id)`, `update(id,dto)`, `remove(id)` (soft). Controller `@Controller('qua-trinh-cong-tac') @UseGuards(JwtGuard)`. Module `forFeature([EmploymentHistory, Employee])` (cần Employee repo để snapshot + apply).

- [ ] **Step 1 (RED):** `service.spec.ts` (mirror `hop-dong.service.spec.ts`), cases: (a) `create` điều chuyển → history có `phongBanCu` = phòng ban hiện tại của Employee, `phongBanMoi` = dto; và Employee.phongBan được cập nhật = giá trị mới (mock employeeRepo.findOne trả employee hiện tại + verify employeeRepo.save gọi với phongBan mới); (b) `create` đổi trạng thái → cập nhật Employee.trangThai; (c) chỉ các trường có trong dto (`*Moi`) mới được apply, trường khác giữ nguyên; (d) `create` với employeeId không tồn tại → NotFoundException; (e) `findAll` filter theo employeeId, sort theo ngayHieuLuc/ createdAt giảm dần (mới nhất trước); (f) `remove` soft. Dùng `find({where})`/`findOne({where})`, KHÔNG `count({where})`. Run `yarn test qua-trinh` → FAIL.
- [ ] **Step 2 (GREEN):** Implement service:
  - `create(dto)`: `emp = await employeeRepo.findOne({ where: { _id-hoặc-id: dto.employeeId } })` (dùng cách repo hiện có định danh — tham chiếu nhan-vien.service `findOne`); nếu không có → `NotFoundException('Không tìm thấy nhân viên')`. Snapshot: `phongBanCu=emp.phongBan, chucDanhCu=emp.chucDanh, trangThaiCu=emp.trangThai`. Tạo history record (denorm employeeName/employeeCode từ emp; `*Moi` từ dto; `*Cu` từ snapshot). Save history. Apply: gán `emp.phongBan=dto.phongBanMoi ?? emp.phongBan`, tương tự chucDanh/trangThai; `employeeRepo.save(emp)`. (mucLuong chỉ lưu vào history, KHÔNG ghi vào Employee vì Employee không có trường mức lương.)
  - `findAll(filter?)`: `find({where})` + sort ngayHieuLuc desc (client-side sort nếu cần); default isActive=true (coercion đúng như nhan-vien).
  - `findOne`, `update`, `remove` (soft).
  Run `yarn test qua-trinh` → PASS.
- [ ] **Step 3:** DTOs (class-validator): `CreateDto` (employeeId + loaiThayDoi + ngayHieuLuc required; `phongBanMoi/chucDanhMoi/trangThaiMoi/mucLuongMoi/soQuyetDinh/lyDo/ghiChu` optional), `UpdateDto` (partial).

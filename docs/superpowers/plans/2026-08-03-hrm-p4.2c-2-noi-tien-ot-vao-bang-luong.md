# P4.2c-2 — Nối tiền làm thêm vào bảng lương, TN miễn thuế, phí công đoàn — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tiền làm thêm đã chốt ở bảng 03-LĐTL chảy vào `thucLinh` của bảng lương chính, phần chênh ca đêm được miễn thuế TNCN đúng luật, và phí công đoàn 2% trừ vào lương mà không làm giảm thu nhập tính thuế.

**Architecture:** Engine `tinhDongLuong()` nhận thêm hai con số **đã tính sẵn** (`tienOt`, `otMienThue`) thay vì tự dựng lại công thức OT — bảng lương thêm giờ là nguồn sự thật duy nhất của tiền OT, engine chỉ tiêu thụ. `thuNhapMienThue` đổi nghĩa thành cột GỘP để hiển thị, nhưng hai thành phần gốc (`mienThueKhoan`, `otMienThue`) vẫn được lưu riêng vì tờ khai 05/KK-TNCN cần chúng tách nhau. Phí công đoàn tính sau thuế, độc lập hoàn toàn.

**Tech Stack:** NestJS 10 + TypeORM (MongoDB), Jest (backend); React 18 + Vite + antd + Vitest (frontend); yarn (be), npm (fe); Node 22.

**Spec:** `docs/superpowers/specs/2026-08-03-hrm-p4.2c-tien-lam-them-gio-design.md` §2, §2.1, §2.2, §3, §4, §7

## Task 2: Engine — khoản `TIEN_OT` và cột TN miễn thuế gộp

**Files:**
- Modify: `be/libs/entities/src/luong/luong.types.ts`

- Test: `be/libs/core/src/luong/tinh-luong.spec.ts`

**Interfaces:**
- Consumes: `phiCongDoan` (Task 1)
- Produces:
  ```ts
  LoaiCongThuc thêm: 'TIEN_OT'
  DauVaoDongLuong thêm:
    /** Tổng tiền làm thêm từ bảng 03-LĐTL ĐÃ CHỐT của kỳ. */
    tienOt: number;
    /** Phần chênh được miễn thuế TNCN, tính từ chính bảng đó. */
    otMienThue: number;
  KetQuaLuong thêm:
    /** Phần miễn thuế đến từ KHOẢN LƯƠNG (ăn ca ≤ trần…) — tách khỏi cột gộp. */
    mienThueKhoan: number;
    /** Phần chênh OT được miễn — tách khỏi cột gộp. */
    otMienThue: number;
  KetQuaLuong ĐỔI NGHĨA:
    thuNhapMienThue = giamTru + mienThueKhoan + otMienThue
  ```

**Vì sao `tienOt` là số ĐÃ TÍNH SẴN, không phải giờ theo loại:** spec §2 phác `gioOtTraTien: Record<string, number>` rồi để engine tự nhân đơn giá × hệ số. Bỏ hướng đó — nó dựng lại y nguyên công thức mà `tinhDongThemGio()` đã có, tạo **hai nguồn sự thật** cho cùng một con số, và hai bên lệch nhau ngay lần đầu kế toán sửa tay một dòng trên bảng 03-LĐTL (chính điều spec §5 cấm). Bảng thêm giờ tính tiền; engine tiêu thụ.

**Vì sao vẫn lưu riêng `mienThueKhoan` và `otMienThue`:** cột gộp là để KẾ TOÁN đọc. Tờ khai 05/KK-TNCN cần "thu nhập miễn thuế" và "các khoản giảm trừ" ở hai dòng khác nhau — gộp mất luôn khả năng điền tờ khai. Lưu cả ba, hiển thị cột gộp.

```ts
describe('TIEN_OT và TN miễn thuế gộp (P4.2c-2)', () => {
  it('HỒI QUY: tienOt = 0 thì thuNhapTinhThue và thue KHÔNG đổi', () => {
    // Bài quan trọng nhất: đổi NGHĨA cột không được đổi SỐ THUẾ của ai.
    const dv = { ...dauVaoMacDinh(), tienOt: 0, otMienThue: 0 };
    const r = tinhDongLuong(dv, chMacDinh());

    expect(r.thuNhapTinhThue).toBe(
      Math.max(0, r.tongThuNhap - r.mienThueKhoan - r.bhxh - r.giamTru),
    );
  });

  it('thuNhapMienThue là cột GỘP = giảm trừ + khoản miễn + chênh OT', () => {
    const dv = { ...dauVaoMacDinh(), tienOt: 1_000_000, otMienThue: 300_000 };
    const r = tinhDongLuong(dv, chMacDinh());

    expect(r.thuNhapMienThue).toBe(r.giamTru + r.mienThueKhoan + r.otMienThue);
    expect(r.otMienThue).toBe(300_000);
  });

  it('TN tính thuế = Tổng TN − BHXH − TN miễn thuế (gộp)', () => {
    const dv = { ...dauVaoMacDinh(), tienOt: 1_000_000, otMienThue: 300_000 };
    const r = tinhDongLuong(dv, chMacDinh());

    expect(r.thuNhapTinhThue).toBe(
      Math.max(0, r.tongThuNhap - r.bhxh - r.thuNhapMienThue),
    );
  });

  it('khoản TIEN_OT lấy thẳng dv.tienOt, có làm tròn theo cấu hình', () => {
    const ch = {
      ...chMacDinh(),
      lamTron: 1000,
      khoanLuong: [
        ...chMacDinh().khoanLuong,
        {
          ma: 'TIEN_OT', ten: 'Tiền làm thêm', loaiCongThuc: 'TIEN_OT' as const,
          thamSo: {}, chiuThue: true, tranMienThue: null,
          vaoTongThuNhap: true, vaoBHXH: false, thuTu: 9,
        },
      ],
    };
    const dv = { ...dauVaoMacDinh(), tienOt: 1_503_906.25, otMienThue: 0 };
    const r = tinhDongLuong(dv, ch);

    // Bảng 03-LĐTL giữ phần thập phân; bảng lương chính làm tròn theo `lamTron`.
    expect(r.giaTriTungKhoan.TIEN_OT).toBe(1_504_000);
  });

  it('BẪY THỜI VỤ: lao động thời vụ KHÔNG được giảm trừ gia cảnh chui', () => {
```

```ts
import type { DongThemGioTheoLoai } from '@app/entities';

/**
 * Phần tiền làm thêm được MIỄN thuế TNCN.
 *
 * TT 111/2013 Đ3.1.i miễn phần trả CAO HƠN đơn giá giờ ngày thường. Với một
 * loại hệ số `h`, phần chịu thuế là `soGio × donGiaGio × 1.0` và phần miễn là
 * `soGio × donGiaGio × (h − 1)`.
 *
 * `truMotDonVi` (chế độ `nghi_bu_va_chenh`): hệ số lưu trên bảng ĐÃ là
 * `heSoTra − 1`, nghĩa là toàn bộ khoản trả CHÍNH LÀ phần chênh — miễn hết,
 * không trừ thêm 1 lần nữa.
 *
 * Kẹp về 0: hệ số ≤ 1 cho phần chênh ÂM, mà số âm ở đây làm cột TN miễn thuế
 * tụt xuống — tức thu THỪA thuế của người lao động.
 */
export function tinhOtMienThue(input: {
  theoLoai: Record<string, DongThemGioTheoLoai>;
  donGiaGio: number;
  mienThueChenh: string[];
  truMotDonVi: boolean;
}): number {
  let tong = 0;
  for (const loai of input.mienThueChenh) {
    const p = input.theoLoai?.[loai];
    if (!p) continue;
    tong += input.truMotDonVi
      ? Math.max(0, p.thanhTien)
      : Math.max(0, p.soGio * input.donGiaGio * (p.heSo - 1));
  }
  return tong;
}
```

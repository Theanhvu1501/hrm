# HRM Phase 2.2 — Hợp đồng lao động (records + rule luật) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Checkbox tracking.

**Goal:** Quản lý Hợp đồng lao động gắn với nhân viên: tạo/sửa/xoá, tự sinh số HĐ, vòng đời trạng thái, và rule luật VN (chặn HĐ xác định thời hạn lần thứ 3). Chưa xuất PDF.

**Architecture:** BE module `hop-dong` trong `config-service` (mirror module `nhan-vien` của P2.1), entity `LaborContract` + `ContractCounter` trong DB `nhan_su`, expose `/api/config/hop-dong`. FE feature `hop-dong-lao-dong` theo CHanlder (mirror `ho-so-nhan-vien`), sidebar "Nhân sự → Hợp đồng lao động". Không đụng 3 project cũ.

**Tech Stack:** NestJS 11 + TypeORM Mongo, Jest; React 18 + Vite + antd 6 + CHanlder; Node 22.

## Global Constraints
- Chỉ sửa trong `hrm/`. Không đụng identity/master-seo/task-management.
- Node 22 builds: `nvm use v22.0.0`. Route sẵn: gateway `/config` → config-service.
- Entity tenant-aware (BaseEntity). Số HĐ: `HD` + 4 số, sinh **atomic** per-tenant (mirror `generateEmployeeId` của nhan-vien: dùng native Mongo `findOneAndUpdate({tenantId},{$inc:{seq:1}},{upsert,returnDocument:'after'})`).
- **Rule luật:** tạo HĐ `loaiHopDong='xac_dinh_thoi_han'` cho 1 nhân viên đã có ≥2 HĐ loại đó (còn hiệu lực/không huỷ) → throw ConflictException tiếng Việt rõ ràng.
- Mỗi task: test/verify xanh + 1 commit.
- **DEPLOY: rsync PHẢI có `--exclude=env`** (xem `ops/README.md` — env server là nguồn chân lý, đừng đè). Sau đó `docker compose -f docker-compose.production.yml up -d --build`.

**Files:** Create `be/libs/entities/src/nhan-su/labor-contract.entity.ts`; Modify `be/libs/entities/src/nhan-su/index.ts`.
**Interfaces:** Produces `LaborContract` (collection `labor_contracts`) + `ContractCounter` (`contract_counters`) exported from `@app/entities`.

- [ ] **Step 1:** Create `labor-contract.entity.ts` (mirror `employee.entity.ts` style — extends BaseEntity + `declare module` augmentation):
```ts
import { Entity, Column } from 'typeorm';
import { BaseEntity } from '../base.entity';

@Entity('labor_contracts')
export class LaborContract extends BaseEntity {
  @Column() contractNo: string;              // HD0001 (unique per tenant, service-enforced)
  @Column() employeeId: string;              // Employee._id
  @Column({ nullable: true }) employeeName?: string;  // denormalized (display)
  @Column({ nullable: true }) employeeCode?: string;  // denormalized NV#### (display)
  @Column() loaiHopDong: string;             // thu_viec|xac_dinh_thoi_han|khong_xac_dinh_thoi_han|dich_vu
  @Column({ nullable: true }) ngayBatDau?: string;
  @Column({ nullable: true }) ngayKetThuc?: string;   // null cho không xác định thời hạn
  @Column({ nullable: true }) mucLuong?: number;
  @Column({ nullable: true }) phuCap?: number;
  @Column({ nullable: true }) hinhThucTraLuong?: string;  // gross|net
  @Column({ default: 'du_thao' }) trangThai: string;   // du_thao|dang_hieu_luc|het_han|da_thanh_ly
  @Column({ nullable: true }) ghiChu?: string;
  @Column({ nullable: true }) fileUrl?: string;        // PDF (phase sau)
  @Column({ default: true }) isActive: boolean;
}

@Entity('contract_counters')
export class ContractCounter extends BaseEntity {
  @Column() seq: number;
}

export interface HopDongEntities { LaborContract: typeof LaborContract; ContractCounter: typeof ContractCounter; }
declare module '../entities' { interface Entities extends HopDongEntities {} }
```
- [ ] **Step 2:** `nhan-su/index.ts`: thêm `export * from './labor-contract.entity';`
- [ ] **Step 3:** Verify `nvm use v22.0.0 && cd be && yarn build:config` PASS. Commit: `feat(be): LaborContract + ContractCounter entities`.

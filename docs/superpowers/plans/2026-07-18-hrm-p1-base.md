# HRM (nhan-su) — Phase 1: Base khung Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Biến `hrm/` thành một app con chạy được của platform masterceo — fork base từ master-seo, gỡ sạch nghiệp vụ kế toán, đổi định danh sang `nhan-su`, để login + 4 màn cấu hình (Phân quyền / Vai trò / Thành viên / Tenant) chạy trên DB riêng `nhan_su`.

**Architecture:** Fork & strip. Copy toàn bộ `master-seo/be` + `master-seo/fe` sang `hrm/`, giữ nguyên `libs/auth` (bản copy), gateway + auth-service + config-service; xoá 8 microservice kế toán và các trang FE kế toán. Verify token HS256/RS256 giống hệt master-seo. App tự sở hữu DB `nhan_su`, dùng chung identity-service (SSO) qua HTTP.

**Tech Stack:** NestJS 11 + TypeORM (MongoDB) monorepo (BE); React 18 + Vite 5 + antd 6 + CHanlder/RxJS pattern (FE); Jest (BE test), Vitest + Playwright (FE test); `env-cmd` multi-env.

## Global Constraints

- **KHÔNG sửa 3 project cũ**: `identity-service`, `master-seo`, `task-management`. Mọi thao tác chỉ nằm trong `hrm/`. Fork là COPY (không move, không đổi master-seo).
- **Đăng ký app trong identity** (seed row `apps`, cập nhật CORS) = script/tài liệu độc lập đặt trong `hrm/ops/`, KHÔNG chỉnh source identity-service. Chạy hay không do chủ dự án quyết; P1 verify local dùng fallback login nên không cần.
- **Định danh app**: `appId = 'nhan-su'`, subdomain `nhan-su.masterceo.com.vn`, DB Mongo `nhan_su`.
- **Ports (đổi để chạy song song master-seo local)**: gateway `4000`, auth `4001`, config `4007`, FE dev `8081`. `SERVICE_IDENTITY_URL` giữ `http://localhost:3020`.
- **Không tách package auth** — `libs/auth` copy nguyên khối, giữ path alias `@app/auth`.
- Path alias BE `@app/*` phải khai báo đồng bộ ở CẢ `tsconfig.json > paths` LẪN `package.json > jest.moduleNameMapper`.
- Mỗi task kết thúc bằng verify xanh + 1 commit. Làm trong repo git riêng của hrm.
- Nguồn tham chiếu chi tiết: `hrm/docs/superpowers/specs/2026-07-18-hrm-base-and-phase1-design.md`.

- [ ] **Step 1: Viết `hrm/ops/seed-nhan-su-app.ts`**

Script standalone dùng driver `mongodb` (đã có trong deps), kết nối DB `masterceo_identity` qua biến môi trường, **upsert idempotent**:
```ts
import { MongoClient } from 'mongodb';

// Chạy: IDENTITY_MONGODB_URI=... IDENTITY_DB=masterceo_identity TENANT_ID=<id> npx ts-node hrm/ops/seed-nhan-su-app.ts
async function main() {
  const uri = process.env.IDENTITY_MONGODB_URI;
  const dbName = process.env.IDENTITY_DB || 'masterceo_identity';
  const tenantId = process.env.TENANT_ID; // optional: cấp entitlement cho 1 tenant
  if (!uri) throw new Error('IDENTITY_MONGODB_URI required');

  const client = new MongoClient(uri);
  await client.connect();
  const db = client.db(dbName);

  const app = {
    appId: 'nhan-su',
    name: 'Nhân sự',
    feUrl: process.env.FE_NHAN_SU_URL || 'https://nhan-su.masterceo.com.vn',
    isActive: true,
  };
  await db.collection('apps').updateOne({ appId: app.appId }, { $set: app }, { upsert: true });

  if (tenantId) {
    await db.collection('tenant_apps').updateOne(
      { tenantId, appId: 'nhan-su' },
      { $set: { tenantId, appId: 'nhan-su', isActive: true } },
      { upsert: true },
    );
  }
  console.log('Seeded nhan-su app', tenantId ? `+ tenant_app for ${tenantId}` : '(no tenant)');
  await client.close();
}
main().catch((e) => { console.error(e); process.exit(1); });
```

Tài liệu 2 việc deploy-time (chủ dự án tự thực hiện, KHÔNG nằm trong repo identity):
1. **Seed app**: chạy `seed-nhan-su-app.ts` với `IDENTITY_MONGODB_URI` (và `TENANT_ID` nếu muốn cấp luôn). Hoặc thay bằng gọi API có sẵn: `PUT /api/admin/tenants/:tenantId/apps` body `{"appId":"nhan-su","isActive":true}` (super admin) để cấp entitlement — nhưng catalog `apps` KHÔNG có API nên vẫn cần seed/insert row `apps`.
